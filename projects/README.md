# Expanded Guided Project Library

These are starter guides, not completed work. Every guide provides a safe scope, a step-by-step workflow, project-specific exercises, and an evidence checklist. Complete the lab yourself and add sanitized evidence before changing its status.

## Status meanings
- **Not started:** no lab work yet.
- **In progress:** work underway.
- **Evidence ready:** lab performed and evidence collected.
- **Completed:** report, evidence, limitations, and recommendations reviewed.

Never commit passwords, tokens, private keys, personal data, or confidential employer/client information.
